# AnyWay – Indoor Navigation Platform

**AnyWay** is an indoor navigation platform designed to make complex spaces easy to explore.  
With the companion tool **MapForge**, admins can create detailed maps starting from floor plans by adding destination points, waypoints, and segments.  
Each segment can be defined as accessible or not, ensuring inclusive navigation even for users with reduced mobility.

## 🚀 Key Features
- 🗺️ **MapForge Editor** – build maps from floor plans in a simple and intuitive way  
- 📍 **Custom Points** – add destinations, waypoints, and connection segments  
- ♿ **Accessibility Support** – mark paths as accessible or not to avoid architectural barriers  
- 🔗 **Multi-Floor Connections** – link floors with vertical elements like stairs and elevators  
- 💾 **JSON Export** – save, reload, and manage maps easily  
- 🌐 **Web Platform** – upload and share maps so that users can search, select, and navigate  

## 🏗️ Use Cases
Perfect for:
- 🛍️ Shopping malls  
- 🏥 Hospitals  
- 🖼️ Museums  
- 🌳 Parks  
- 🏢 Any large or complex building  

## 📖 Getting Started
1. Create your map with **MapForge**  
2. Upload it to the platform via the `/loadMap` endpoint  
3. Let users search, select, and navigate with step-by-step guidance
