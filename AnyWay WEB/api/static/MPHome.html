About MapForge

Forge your maps in Any Way you want.

MapForge is the ideal tool for transforming simple images into interactive maps ready to use on the AnyWay platform. With just a few steps, you can define walkable paths, set destinations, and instantly obtain a fully usable map without any technical complications.

⚠ Important note: To use MapForge, the .NET 8.0 framework must be installed on your system. You can intsall it at this link.
